# تصحيح الاختبارات

موقع ثابت (Static) لنشر مواضيع الاختبارات وتصحيحاتها النموذجية — يُستضاف على GitHub Pages.

## إضافة موضوع / تصحيح
1. ضع الملف (PDF أو صورة) في: `files/<السنة>/<القسم>/` مثلاً `files/2026-2027/2as-se/t1-solution.pdf`
2. في `data/config.js` استبدل `null` بمسار الملف:
   ```js
   solution: "files/2026-2027/2as-se/t1-solution.pdf"
   ```
3. ما دامت القيمة `null` يظهر للتلاميذ «يُنشر قريباً».

## سنة دراسية جديدة
انسخ كتلة السنة في `years` (ضعها في الأعلى)، غيّر `id` إلى `"2027-2028"` ثم غيّر `currentYear`.
السنوات القديمة تبقى متاحة من قائمة اختيار السنة.

## رموز الأقسام
| الرمز | القسم |
|---|---|
| `2as-se` | السنة الثانية — علوم تجريبية (رياضيات) |
| `2as-lph` | السنة الثانية — آداب وفلسفة (رياضيات) |
| `1as-l` | السنة الأولى — جذع مشترك آداب (رياضيات) |
| `1as-st` | السنة الأولى — جذع مشترك علوم وتكنولوجيا (إعلام آلي) |
